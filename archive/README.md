# Archive

Earlier iterations and alternate exports are kept here to preserve the project's history. They are not the current specification.

The [final concept](../docs/MoBoOk_Final_Concept.pdf) takes precedence. The latest supplied preview is [Preview 2](../design/previews/MoBoOk-Preview-2.html); its numbering does not establish that every interaction matches the final concept.

| Folder | Preserved files |
| --- | --- |
| `concepts/` | Original concept Markdown, concept v2 PDF and concept v3 PDF |
| `exports/` | PDF exports of the site map and policy draft, whose primary copies are Markdown in `docs/` |
| `mockups/` | Base, v2 and v3 HTML mockups |
| `previews/` | Base and Preview 1 HTML prototypes |

All 16 supplied source files are preserved byte-for-byte across this repository. Filenames have been cleaned of transfer suffixes, but file content has not been rewritten. Read [documentation notes](../docs/README.md) before treating draft policies or earlier features as implementation requirements.
